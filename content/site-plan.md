# Site plan — vanshgoel.com

Theme: **snooker**. Every project is a *frame*; each frame is a ball, highest value first.
Positioning: product designer for B2B SaaS, marketplaces and fintech (not tied to any single case study).

## Home page sections (top to bottom)

1. **Header** — VANSH GOEL logo (cue ball) · Frames · About · Approach · Contact · Resume
2. **Hero** — "I line up the shot before I take it." + intro + snooker table illustration
3. **Scoreboard** — 3+ years · 0 → 1 payout system · 2–5K AI posts in hours · 107% more new users
4. **The Frames** — 4 case study cards (cover image = each folder's `00-` image)
5. **About — Between shots** — bio, BellPost + PrepAud experience, snooker quote, photo
6. **Off the table** — cue rack: Snooker, Journal, Meditation (filled) · Chess, Guitar, Arduino (learning next)
7. **Approach — How I play a frame** — Read the table · Plan the break · Play the shot · Chalk the score
8. **Contact — Fancy a frame?** — LinkedIn, Resume, chalk cube that copies hello@vanshgoel.com
9. **Footer**

## Case study page template

1. Dark green header: ball + frame number + project kicker, title, one-line summary, facts (role, team, timeline, platform, outcome)
2. Hero image (`00-`)
3. Numbered sections, each with a short label on the left and text on the right
4. Infographics run full width under the text they explain
5. Tables for structured content (statuses, edge cases, validation ranges)
6. Results as big number tiles
7. "Next frame" card
